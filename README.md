# 湖南网络学院学习卡｜湘·干教网院课程学习助手

支持已适配平台的视频和文字课程，提供课程列表、账号学时查看、暂停和继续学习功能，视频可选1、1.5、2倍速。

首次登录并核验成功后，可连续试用60分钟。正式授权绑定一个学习账号，有效至激活当年12月31日24:00（北京时间）。

交付安装包、使用说明和激活码。请在**闲鱼/淘宝搜索“湖南网络学院学习卡”**。提供14个市州分院选择，具体适配请试用确认后购买。
